# 여백 — 나의 작은 다이어리

GitHub 저장소: [khn0916/diary](https://github.com/khn0916/diary)

이 폴더를 다이어리 프로젝트의 작업 기준으로 사용합니다. 사이트 호스팅과 배포는 별도 요청 시 진행합니다.

`index.html`을 브라우저에서 열면 사용할 수 있는 월간 다이어리입니다. 별도 설치나 빌드가 필요하지 않습니다.

- 종이 질감, 중앙 접힘 그림자, 겹친 종이 가장자리와 베이지색 배경
- 모든 달에 동일한 7열 × 6행 달력, 이전/다음 달 이동과 오늘로 이동
- 양쪽 아래 모서리를 0.22초 누른 뒤 안쪽으로 드래그하여 종이처럼 페이지 넘기기. 짧게 당기거나 Esc를 누르면 복귀하며, 키보드로 모서리에 초점을 두고 Enter/Space를 눌러도 넘길 수 있습니다.
- 날짜를 눌러 메모와 기분 작성, 수정, 삭제
- 월별 메모와 날짜별 기록을 브라우저 localStorage에 저장
- 좁은 화면에서는 다이어리 영역을 좌우로 스크롤

기록은 현재 브라우저에만 저장되며 다른 기기로 동기화되지 않습니다. 브라우저 데이터를 삭제하면 기록도 삭제됩니다. 안정적인 동일 주소 사용을 위해 로컬 서버에서 여는 것을 권장합니다. Google Fonts를 불러오지 못하면 기본 글꼴로 표시됩니다.

로컬 서버 예시: 이 폴더에서 `python -m http.server 5175` 실행 후 `http://localhost:5175`를 여세요.

## 과제6: Python Plan–Do–See

기존 `index.html`, `style.css`, `app.js`는 변경하지 않고 별도 과제 화면을 추가했습니다. 새 화면에는 JavaScript를 추가하지 않았으며 HTML 폼의 처리를 Python 서버가 담당합니다.

```text
python server.py
```

- 원래 다이어리: http://127.0.0.1:5175/
- 계획·실행·회고: http://127.0.0.1:5175/pds
- Python 3.10 이상, 표준 라이브러리만 사용하므로 패키지 설치가 필요하지 않습니다.
- PDS 기록은 `data/diary.sqlite3`에 저장됩니다. `PDS_DB` 환경 변수 또는 `--db` 옵션으로 저장 위치를 지정할 수 있습니다.
- 원래 다이어리의 메모는 기존대로 브라우저에 저장됩니다. PDS 데이터만 서버 DB에 저장되며 두 저장소를 자동으로 합치지 않습니다.
- 계획 이력, 할 일 CRUD·검색·필터·정렬, 실행 기록, 중복 완료 방지, 회고 집계와 근거 링크, 개선점의 다음 계획 연결, 전체 JSON 내보내기를 제공합니다.
- 최초 DB는 비어 있습니다. 본인의 실제 기록은 나중에 직접 입력합니다.
- 로그인과 접근 제어가 없습니다. **배포한 링크를 아는 사람은 조회뿐 아니라 생성·수정·삭제·전체 내보내기도 할 수 있습니다.** 공개해도 괜찮은 내용만 입력하세요.
- 기본 실행은 로컬 컴퓨터에서만 접속 가능합니다. 호스팅은 별도 요청 후 진행하며, Python 실행과 영속 DB 저장 공간이 필요합니다. GitHub Pages는 Python 서버를 실행하지 않습니다.
- 개발용 표준 라이브러리 HTTP 서버입니다. 공개 배포 전에는 호스팅 환경의 서버 운영·TLS·요청 제한과 DB 영속 디스크 설정을 검토해야 합니다.

# 여백 — 나의 작은 다이어리

GitHub 저장소: [khn0916/diary](https://github.com/khn0916/diary)

이 폴더를 다이어리 프로젝트의 작업 기준으로 사용합니다. 사이트 호스팅과 배포는 별도 요청 시 진행합니다.

`index.html`을 브라우저에서 열면 사용할 수 있는 월간 다이어리입니다. 별도 설치나 빌드가 필요하지 않습니다.

- 종이 질감, 중앙 접힘 그림자, 겹친 종이 가장자리와 베이지색 배경
- 모든 달에 동일한 7열 × 6행 달력, 이전/다음 달 이동과 오늘로 이동
- 양쪽 아래 모서리를 0.22초 누른 뒤 안쪽으로 드래그하여 종이처럼 페이지 넘기기. 짧게 당기거나 Esc를 누르면 복귀하며, 키보드로 모서리에 초점을 두고 Enter/Space를 눌러도 넘길 수 있습니다.
- 날짜를 눌러 메모와 기분 작성, 수정, 삭제
- 월별 메모와 날짜별 기록을 브라우저 localStorage에 저장
- 좁은 화면에서는 다이어리 영역을 좌우로 스크롤

기록은 현재 브라우저에만 저장되며 다른 기기로 동기화되지 않습니다. 브라우저 데이터를 삭제하면 기록도 삭제됩니다. 안정적인 동일 주소 사용을 위해 로컬 서버에서 여는 것을 권장합니다. Google Fonts를 불러오지 못하면 기본 글꼴로 표시됩니다.

로컬 서버 예시: 이 폴더에서 `python -m http.server 5175` 실행 후 `http://localhost:5175`를 여세요.
